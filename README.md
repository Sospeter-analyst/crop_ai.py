# 🌱 AI Crop Recommendation System

This is a beginner Artificial Intelligence project that recommends the best crop to plant based on environmental conditions.

## 📌 Project Description
The system uses basic AI logic to analyze:
- Soil type
- Rainfall
- Temperature

Based on these inputs, it suggests the most suitable crop for farming.

## 🚀 Features
- Simple and fast crop prediction
- Beginner-friendly AI project
- Can be expanded into a real farming assistant app

## 🧠 Technologies Used
- Python

## ▶️ How to Run
1. Open the Python file
2. Run the program
3. View the recommended crop output

## 📸 Sample Output
Example:
🌱 Recommended crop: maize
